# 🚀 Quick Start Guide - TheMealDB Recipe App

## ⚡ Get Started in 3 Minutes

### Step 1: Install & Start
```bash
npm install
npm start
```

### Step 2: Choose Platform
- Press `a` for Android
- Press `i` for iOS  
- Press `w` for Web

### Step 3: Scan & Explore!
- Use Expo Go app to scan QR code
- Or run on emulator/simulator
- **No API keys needed** - TheMealDB is 100% free!

## 📱 Common Tasks

### Search for a Recipe
1. Scroll to search bar
2. Type meal name (e.g., "pasta")
3. See results instantly
4. Tap result to view details

### Save a Recipe
1. View recipe details
2. Tap ⭐ (star icon)
3. See "Added to favorites!" message
4. View in My Favorites anytime

### Remove from Favorites  
1. Go to "My Favorites"
2. Find the recipe
3. Tap ✕ button on right
4. Confirm removal

### Watch Cooking Video
1. View recipe details
2. Scroll to bottom
3. Tap "Watch on YouTube"
4. Video opens in browser

## 🆘 First Time Issues?

### App won't load?
```bash
npm install
npm start -- --clear
```

### No recipes showing?
- Check internet connection
- TheMealDB API may be slow
- Pull down to refresh
- Try again in a moment

### Favorites not saving?
- App shows notification on save
- Check device storage isn't full
- Force close and reopen app

### Search returns nothing?
- Try different keyword
- Use English names
- Search something common first
- Check internet connection
